# Creative Corner music assets

The current catalog expects the four MP3 files from `KnowerLife/creative-corner`:

- `1.mp3` — Кованое сердце
- `3.mp3` — Сердце дома
- `4.mp3` — Simulation Hacker
- `2.mp3` — Хакер Симуляции

The unified Pages workflow imports these files from the current Creative Corner repository until the manual **Import Creative Corner MP3s into main** workflow is run once.
