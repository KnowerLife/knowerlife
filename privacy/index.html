Политика конфиденциальности

Сайт работает на GitHub Pages. Большинство данных обрабатывается локально в браузере, а аналитика загружается только после явного согласия.

Обновлено 3 августа 2026 года

01Без собственной базы

01 / Принципы

Какие данные обрабатывает сайт

KnowerLife — статический сайт на GitHub Pages. Он не использует собственный backend, учетные записи пользователей или серверную базу данных для сохранения содержимого форм и браузерных инструментов.

Важно

Не вставляйте реальные пароли, секретные ключи, персональные JWT или производственные API-токены в примеры, если устройство вам не принадлежит.

02 / Обращения

Контактная форма

Форма формирует ссылку mailto: и открывает почтовое приложение пользователя. Данные не отправляются автоматически: письмо уходит только после подтверждения в выбранном почтовом приложении.

После отправки обработка письма происходит у почтовых провайдеров отправителя и получателя в соответствии с их правилами конфиденциальности.

03 / Browser lab

Локальные инструменты

Генератор паролей, JSON formatter и diff, Base64, JWT decoder, SHA, Regex, CSV-конвертер и проектные генераторы выполняются JavaScript-кодом непосредственно в браузере.

  • введённые данные не отправляются на сервер KnowerLife;
  • результаты не сохраняются сайтом после закрытия страницы;
  • скачивание файлов запускается локально средствами браузера.

04 / Browser storage

Хранилище браузера

В localStorage могут сохраняться выбранная тема, режим отображения портфолио и решение относительно аналитики. Эти данные находятся в браузере пользователя и могут быть удалены через настройки сайта или браузера.

05 / Analytics

Яндекс.Метрика

Скрипт Яндекс.Метрики загружается только после нажатия кнопки согласия. Используются отчёты о посещении и переходах. Запись действий пользователя через Webvisor отключена.

До согласия запрос к сервису аналитики не выполняется. Выбор можно изменить кнопкой «Настроить аналитику» в содержании этой страницы.

06 / Third parties

Внешние ссылки и платформы

Сайт содержит ссылки на GitHub, Telegram, VK, email и сайты проектов. При переходе на внешнюю платформу обработка данных регулируется её собственной политикой.

07 / Control

Как управлять локальными данными

  1. Откройте настройки сайта в браузере.
  2. Удалите cookies и данные сайта для домена knowerlife.ru.
  3. При следующем посещении сайт снова предложит выбрать режим аналитики.
