Документ

Конфиденциальность

Сайт работает на GitHub Pages и не использует собственную серверную базу данных.

Контактная форма

Форма формирует ссылку mailto: и открывает почтовое приложение пользователя. Данные не отправляются владельцу сайта, пока пользователь самостоятельно не отправит подготовленное письмо.

Локальные инструменты

Пароли, JSON, тексты и проектные брифы обрабатываются JavaScript-кодом на устройстве пользователя. Сайт не отправляет их на сервер.

Локальное хранилище

В localStorage сохраняются выбор темы и решение относительно аналитики.

Аналитика

Яндекс.Метрика загружается только после явного согласия. Webvisor отключён. Отозвать выбор можно, очистив данные сайта в настройках браузера.
